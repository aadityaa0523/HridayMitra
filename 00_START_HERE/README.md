# Start here

**HridayMitra turns any chair at home into a 90-second heart-failure check-in.** The family's own chair stands on a thin weighing platform with foot plates; the elder holds a sensor bar on the lap or fixed to the armrests. It learns each person's normal and warns the family by SMS about 3 days before a hospital visit, with the reason in plain words. Build cost ₹4,402.
